# AWS Solutions Architect Journey

A public record of my AWS and cloud learning journey, focused on architecture, infrastructure, security, networking, containers, observability, and AI on AWS.

This repo is organised around how real systems are designed and operated, not just around memorising services. The goal is to build strong architecture judgement, understand trade offs, and develop towards solutions architect and platform focused roles.

## Why this repo exists

I want one place to document how I am learning to design secure, reliable, scalable, and cost aware systems on AWS.

This repo is intended to help me:

- strengthen cloud fundamentals
- improve architecture thinking
- document hands on AWS work
- connect AI workloads to cloud infrastructure
- build towards solutions architect and platform engineering roles

## What this repo covers

### 01 Cloud Foundations
Core cloud concepts, global infrastructure, elasticity, scalability, pricing basics, and shared responsibility.

### 02 AWS Core Services
A high level map of core AWS building blocks and when to use them.

### 03 Identity and Security
IAM, roles, policies, least privilege, encryption, key management, and secrets handling.

### 04 Networking
VPCs, subnets, routing, security groups, NACLs, DNS, load balancers, and private connectivity.

### 05 Compute
EC2, Lambda, ECS, EKS, Fargate, Auto Scaling, and compute trade offs.

### 06 Storage
S3, EBS, EFS, lifecycle management, backups, and storage design choices.

### 07 Databases
RDS, DynamoDB, ElastiCache, and selecting the right data store for different workloads.

### 08 Serverless and Event Driven
SQS, SNS, EventBridge, Step Functions, and asynchronous system design.

### 09 Containers and Orchestration
Docker, ECS, EKS, service discovery, scaling, and deployment patterns.

### 10 Observability and Operations
CloudWatch, logs, metrics, alarms, tracing, and operational monitoring.

### 11 Infrastructure as Code
Terraform, remote state, modules, environments, and repeatable infrastructure.

### 12 CI/CD
GitHub Actions, OIDC, automated delivery, rollback thinking, and deployment workflows.

### 13 Architecture Patterns
Three tier applications, microservices, event driven systems, APIs, and workload design patterns.

### 14 Well Architected Design
Security, reliability, performance efficiency, cost optimisation, operational excellence, and sustainability.

### 15 AI and ML on AWS
AI practitioner aligned topics, Bedrock, model deployment patterns, responsible AI, governance, and ML workloads on AWS.

### 16 Case Studies
Short architecture write ups where I compare options, justify design choices, and explain trade offs.

### 17 Projects
Hands on AWS projects covering deployment, migration, infrastructure, and production style patterns.

### notes
Summaries, quick revision sheets, diagrams, and useful references.
